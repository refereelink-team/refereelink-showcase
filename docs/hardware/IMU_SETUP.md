# Yahboom IMU 接入与实物验收

## 官方依据与当前支持范围

- [用户指定的高精度 IMU 学习页面](https://www.yahboom.com/study/IMU_Sensor)：当前六轴、九轴、十轴模块。
- 页面下载专区的通信协议工作簿已于 2026-10-16 下载核对；来源、校验和与字节格式见 [PROTOCOLS.md](PROTOCOLS.md)。原件和提取码不放入 Git。
- [官方资料仓库](https://github.com/YahboomTechnology/IMU-Sensor/tree/61eda112c249cab6947d1ac1313a26749aa9f593) 的模块介绍、PC 通讯及树莓派串口教程已核对。

Showcase 接收 `7E 23` 协议的 `0x04` 原始数据帧，仅展示三轴加速度，单位为 m/s²，**含重力、沿传感器自身坐标轴**。陀螺仪、磁力计、欧拉角、四元数和气压计未接入展示或融合定位；六轴/九轴/十轴对应数据能力不同。旧款 `55 51` 协议不兼容。本项目不提供 I²C 接口，也不通过积分加速度推算足球位置。

## 1. 接线与配置

1. 使用可传输数据的 Type-C 线将 IMU 连接到 **同一台运行前后端的 PC**，按 [WSL 本地部署指南](../LOCAL_WSL.md#3-把-a1-和-imu-的-usb-交给-wsl) 用 `usbipd-win` 将 IMU 的 USB 转接给 WSL2 Ubuntu 后端。仅 Windows 识别设备不代表 WSL 可读取；页面填写 Linux `/dev/…`，不填 Windows COM 号。显式选择远程后端时，本机串口不会自动转发。
2. 官方模块参数为 115200 baud，PC 示例为 8N1；默认输出 25 Hz，可通过厂商工具调整为 10–100 Hz。上电启动时间约 5 秒，等待初始化结束再判断是否收不到数据。
3. 若使用排针 UART，先按具体板卡资料确认供电、电平和引脚，TX 接接收端 RX，并共地；不要将 TTL UART 直接接到 RS-232。优先用 USB，避免照搬其他传感器的线色或接线方案。
4. 使用 `lsusb` 与 `ls -l /dev/serial/by-id/` 确认设备；也可使用 `/dev/ttyUSB0` 等路径。官方教程指出无法识别串口时检查 CH340 驱动；先检查系统日志和现有驱动，不要盲目卸载服务或安装第三方内核模块。确保后端服务用户有串口权限，不要全员放开设备权限。
5. 先用串口助手 HEX 模式确认 `7E 23 17 04` 开头的 23 字节原始帧及末尾 sum8 校验。串口助手/厂商上位机必须关闭后再连接 showcase，不能同时占用端口。
6. 打开“足球定位”→“设备数据”，停止演示，填写 IMU 串口。只验证 IMU 时，UWB 串口留空；两设备同时使用时必须填写各自独立端口。
7. 点击“连接串口”。`串口已打开`不等于已收到有效数据；应出现`有效数据`且三轴加速度持续更新。后台重启后配置需重新填写。参数修改需先断开。

Showcase 只读串口，不自动发送校准、复位、输出频率或算法切换命令。需调整时用厂商工具并遵守其静置/校准要求；不要把校准值或设备标识提交 Git。

## 2. 无数据或数据异常

| 现象 | 检查 |
| --- | --- |
| 无串口 | 数据线是否支持传输、USB连接、CH340驱动、后端所在主机 |
| 端口打开失败 | 路径、权限、是否被官方工具占用、是否与 UWB 填了同一端口 |
| 串口打开但数据过期 | 上电等待、115200/8N1、当前模块是否是 `7E 23` 协议、是否有 `0x04` 原始帧 |
| `imu_bad_checksum` | 波特率、接线、噪声或帧损坏；不能关闭校验来“修复” |
| `invalid_imu_length` / `invalid_imu_raw_payload_length` | 模块型号/固件协议是否匹配；不要按旧款 `55` 协议解析 |
| 有姿态数据但加速度仍过期 | 只有 `0x04` 被计为有效加速度；其他功能帧不会刷新该状态 |
| 静止时某轴接近 ±9.81 而非 0 | 加速度包含重力；旋转安装方向会改变各轴分量，这是预期行为 |

累计拒帧与最近原因用于诊断；历史拒绝原因不会因新帧成功而自动清空。缺少正确帧头的数据可能直接被跳过，因此拒帧数为 0 也不能证明设备正常。

## 3. 实物验收

- 记录实际六轴/九轴/十轴型号、固件、接线和安装轴向；保留真实串口采集在 Git 外。
- 与厂商工具对照同一真实帧的原始有符号 XYZ 和单位换算：`raw × 16 / 32767 × 9.80665`。
- 静止时检查加速度模长接近当地重力大小；翻转/旋转模块检查轴向变化，并与官方工具比较。此检查不是已验证的误差标定。
- 拔线应变成错误或数据失效，不得继续把旧值当实时值；重连后应恢复。
- 单独 IMU 与 UWB+IMU 双端口分别测试，确认没有启动演示回放。

软件单元测试与 Linux PTY 测试不验证实物精度、球内冲击、供电或安装。`hardware_verified=false` 保持不变。
